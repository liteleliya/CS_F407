# Lab 3: Search and A*

A* (with pluggable heuristics) and BFS for the warehouse robot, with the handout's tests, a BFS vs A* comparison, and a heuristic investigation that checks admissibility against exact h*.

## Files

- `astar.py` - problem representation, A*, BFS, tests, and experiments (pure Python, no libraries).
- `results.txt` - output of `python3 astar.py`.
- `SUBMISSION.md` - the full lab report (formulation, design, prompts, results, reflections).

## Running it

```bash
python3 astar.py
```

The exit code is 0 only if all tests pass.
