# Lab 2: Agents

A goal-based agent that plans a collision-free, shortest path through the warehouse map using breadth-first search.

## Files

- `warehouse_agent.py` - environment model, goal-based agent, tests, and a scaling experiment.
- `results.txt` - output of `python3 warehouse_agent.py --tests`.
- `SUBMISSION.md` - answers to Tasks 1 to 3, the agent design and block diagram, the prompt, and test results.

## Running it

```bash
python3 warehouse_agent.py            # solve the lab map
python3 warehouse_agent.py --tests    # plus tests and the scaling experiment
```
