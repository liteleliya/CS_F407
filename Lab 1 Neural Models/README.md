# Lab 1: Neural Models

XOR "sensor disagreement" experiments with a 2-2-1 PyTorch network: linear baseline, backpropagation checks, symmetry, activation comparison, and a three-class softmax extension.

## Files

- `xor_lab.py` - runs every experiment in the handout (Tasks 1, 4A to 4D, 5).
- `results.txt` - full output of `python3 xor_lab.py`.
- `SUBMISSION.md` - problem specification, design, LLM prompt, results tables, and reflection answers.

## Running it

Requires Python 3 and PyTorch (CPU is enough). Takes about a minute.

```bash
python3 xor_lab.py
```
